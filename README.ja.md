# 2D姿勢推定を用いた人間行動認識

🇺🇸 English → [README.md](README.md)

2D姿勢キーポイントから人間の行動を認識するための機械学習パイプラインです。本プロジェクトでは、特徴量エンジニアリング、スケルトン正規化、および Leave-One-Subject-Out（LOSO）交差検証を用いた被験者非依存評価に重点を置いています。

---

## 概要

人間行動認識（Human Activity Recognition: HAR）は、医療、監視システム、支援技術などの分野で広く利用されています。本プロジェクトでは、生画像を直接使用する代わりに、2D人体姿勢キーポイントを用いて身体の動きを表現することで、プライバシーを保護しながら計算コストを削減しています。

本パイプラインでは、姿勢系列データから幾何学的特徴量および時間的特徴量を抽出し、その後、Random Forest などの従来型機械学習モデルを学習させます。

主な目的は、未知の被験者に対しても高い汎化性能を持つモデルを構築することです。

---

## パイプライン

```
生の姿勢キーポイント
        │
        ▼
無効なフレームの除去
        │
        ▼
スケルトン正規化
（腰中心への位置合わせ + 身体スケーリング）
        │
        ▼
特徴量エンジニアリング
    • 関節角度
    • 可動域
    • 速度
    • 加速度
        │
        ▼
マルチスケール時間窓
（短期 + 長期の時間的コンテキスト）
        │
        ▼
特徴量集約
（平均、標準偏差、最小値、最大値）
        │
        ▼
Random Forest 分類器
        │
        ▼
Leave-One-Subject-Out 評価
```

## 特徴

### スケルトン正規化

体格やカメラ位置によるばらつきを低減するために、以下の処理を行います。

* 腰の中心を座標系の原点として使用します。
* 座標を胴体の高さ（または肩幅）で正規化します。

これにより、異なる被験者間でも姿勢データを直接比較できるようになります。

---

### 特徴量エンジニアリング

各フレームから以下の特徴量を抽出します。

#### 幾何学的特徴量

* 関節角度
* 肩関節の角度
* 膝関節の角度
* 首から胴体への角度

#### 可動域特徴量

* 肩に対する手首の高さ
* 腰に対する手首の高さ
* 手首と鼻の距離
* 手首の対称性

#### 時間的特徴量

* 関節速度
* 関節加速度

---

### マルチスケール時間窓

単一の時間窓サイズを使用するのではなく、本パイプラインでは異なる2つの時間スケールに対して同時に統計量を計算します。

例:

* 短時間窓: 15フレーム
* 長時間窓: 60フレーム

各特徴量について、以下の統計量を計算します。

* 平均
* 標準偏差
* 最小値
* 最大値

これにより生成される特徴ベクトルは、短期的な動きと長期的な姿勢の両方を表現できます。

---

### モデル

本プロジェクトで評価を行っている主なモデルは以下の3つです。

- Random Forest（ベースライン）
- Extra Trees
- XGBoost

Random Forest をベースラインモデルとして特徴量エンジニアリングおよび各種実験を実施し、その後、最適化した前処理パイプラインとハイパーパラメータを用いて Extra Trees および XGBoost の性能を比較・評価しています。

また、本プロジェクトには Logistic Regression、SVM、K-Nearest Neighbors（KNN）、AdaBoost、Decision Tree、Histogram Gradient Boosting、Gaussian Naive Bayes などの分類器や、LSTM モデルの実装およびデフォルトのハイパーパラメータ設定も含まれています。これらは将来的な比較実験や拡張を容易にするために実装されており、現時点での評価結果には含まれていません。

---

## 評価

本プロジェクトでは **Leave-One-Subject-Out（LOSO）** 交差検証を採用しています。

各反復では、以下の手順で評価を行います。

1. 1名の被験者をテストデータとして除外します。
2. 残りの被験者を学習データとして使用します。
3. Macro F1スコアを算出します。
4. 各フォールドごとに分類レポートを生成します。

この評価方法により、未知の被験者に対するモデルの汎化性能を現実的に評価できます。
